# MD → 公众号排版工具

把 Markdown 一键排版成「公众号兼容的全内联样式 HTML」，支持多主题切换（参考 mdnice 的主题体系），复制富文本后直接粘贴进公众号编辑器即可使用。

## 快速开始

```bash
npm install
npm run dev      # 打开 http://localhost:5173
```

## 使用流程

1. 左侧粘贴 Markdown，或点击「打开 .md」/直接拖入文件
2. 工具栏下拉选择主题：蓝色科技（默认）/ 橙心 / 姹紫 / 绿意 / 凝夜
3. 文中引用的本地图片：点「选择图片」载入（按文件名匹配，自动转 base64 内嵌）
4. 右侧实时预览 → 点「复制富文本」→ 粘贴进公众号编辑器
5. 也可「复制 HTML」拿源码，或「导出」下载独立 HTML 文件

## Markdown 约定

| 写法 | 渲染效果 |
|---|---|
| `## 01 标题` | 二级标题带渐变色块序号 |
| `> 引用块` | 主题色提示框（写在前面/划重点等） |
| `> —— 署名` | 引用块内以「——」开头的段落渲染为灰色小字签名 |
| 围栏代码块 ` ```php ` | 深色代码窗口（红黄绿圆点 + 语言标签 + 语法高亮） |
| `![图 1 · 说明](img.jpg)` | 居中图片 + 灰字图注；alt 不含「图 N ·」时自动编号 |
| 无序/有序列表 | 渐变圆点 / 数字前缀段落 + 悬挂缩进（公众号下比 ul 更稳） |
| `[链接](url)` | 主题色加粗文字（公众号正文外链无效，故丢弃 href） |

## 排版规则来源

样式 token 集中在 `src/core/themes.js`：`buildTheme(调色板)` 工厂 + 5 套色板，结构复刻自已验证的成品 `../PHP 8.6 将迎来原生并发能力.html`。新增主题只需追加一个调色板对象（约 15 个色值：主色/深色/亮色/强调色、引用块底色、代码块底色与语法高亮色板等）。

## 测试

```bash
npm test    # 用内置示例文章渲染并校验 28 项关键样式（含多主题）
```

## 构建部署

```bash
npm run build   # 产物 dist/，base 为相对路径，可直接放静态托管 / GitHub Pages
```

## 公众号粘贴注意事项

- 粘贴后如个别样式丢失，优先检查：渐变背景（已做纯色降级）、图注、代码块
- 图片以 base64 粘贴，公众号编辑器会自动转存；单图建议 < 5MB
- 正文外链会被公众号过滤，工具已把链接渲染为蓝色加粗文字
