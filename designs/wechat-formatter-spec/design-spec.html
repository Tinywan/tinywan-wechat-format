01产品定位

把 Markdown 一键排版成「公众号兼容的全内联样式 HTML」的在线工具：左侧编辑、右侧实时预览，复制富文本后直接粘贴进公众号编辑器。三条硬约束决定全部设计：

  • 微信兼容——输出只允许内联 style，无 class、无 <style> 块，任何元素不依赖继承；
  • 多主题——同一份 Markdown 可切换 5 套文章主题，色板集中在 src/core/themes.js 工厂生成；
  • 本地图片——按文件名匹配并转 base64 内嵌，粘贴后由公众号自动转存。

02UI 设计语言（编辑器）

编辑器界面参考 Kami 的纸感体系：羊皮纸画布上悬浮象牙白纸张，唯一强调色为墨蓝，中性色全部带暖调，无硬投影。

  • 列表项公共：16px / 1.7 / 字距 1px / 两端对齐，padding-left:16px; text-indent:-16px 悬挂缩进，margin 0·0·18；
  • 无序：8px 渐变圆点（主色→亮色 135°，纯色降级），margin-right:8px; vertical-align:2px；
  • 有序：主色加粗 N. + 不换行空格；渲染器维护计数器，嵌套各层独立计数；
  • 嵌套缩进：每深一层前缀 4 个 \u00a0。

引用块（输出为 section 卡片）

  • 外框：浅底 #eaf2fa + 左 4px 主色竖线 + 圆角 4 + padding 14·16，margin 0·0·20；
  • 文字：15px / 1.9 / 字距 1px；非末段 margin 0·0·8 留缝，末段 margin 0；
  • 以 —— 开头的段落判为签名行：13px、灰字 #8a94a0；
  • 引用内加粗着主色。

图片与图注

  • 图按文件名匹配本地文件 → base64 内嵌（微信不加载外链图）；未匹配加红色虚线外框并计入警告；
  • 图：max-width:100%; display:block; margin:0 auto，容器居中；
  • 图注：自动生成「图 N · alt」（alt 已带编号则不重复；alt 空取文件名），12px 灰字居中，margin 0·0·20。

代码块（窗口风格）

  • 外框：深底 #2a2f3a、圆角 6、padding 16·14，margin 0·0·20；
  • 头部（有语言/标题时）：macOS 三圆点（#ff5f57/#febc2e/#28c840）+ 11px 标签 LANG · 标题（如 ```php app.php）；
  • 代码行：13px / 1.9 等宽，空格硬化 \u00a0，word-break:break-all 长行折行；
  • 首行整行注释 → 标题行：加粗、着 #c678dd；
  • 语法高亮：hljs → class 转内联色（深色底用 One Dark，绿意主题浅色底用 GitHub Light）。

表格

  • table：border-collapse:collapse; width:100%，margin 0·0·20；
  • th：主色底白字、14px 加粗、字距 1px、padding 10·12、1px 主色边框、左对齐；
  • td：14px / 1.7、padding 10·12、1px 浅边框 #d5e2ef、vertical-align:top。

06微信兼容约束

  • 仅内联 style；不输出 class、<style>、ul/ol（列表转为段落 + 标记）；
  • 渐变一律先写纯色降级：background:#2273b8;background:linear-gradient(…)；
  • 代码空格硬化为 \u00a0 保对齐，同时 word-break:break-all 允许长行折行；
  • 外链渲染为主题色加粗文字（公众号正文外链无效，丢弃 href）；
  • 每个文字元素自带完整字体栈，不依赖继承。
